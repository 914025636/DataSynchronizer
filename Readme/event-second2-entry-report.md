# 公布后第 2 秒确定方向并入场：回测报告

> 标的：币安 BTC/USDT 现货 · 数据：1 秒 K 线 · 样本：**161 个**美国高影响事件窗口 · 区间：**2023-01-06 至 2026-09-11**
>
> **重要更新（2026-09-12）**：补入 2026-09-10 PPI 与 2026-09-11 CPI 两个窗口后重算，样本为 **161 个窗口、51 笔交易**。结论未变：胜率 **51.0%**，单笔平均 **+0.102%**，扣除 0.1% 成本后仅 **+0.12%**，仍与零无法区分。

## 一、规则定义

| 项目 | 设定 |
|---|---|
| 信号 | 公布当秒开盘价 → **第 2 秒收盘价**的涨跌幅 |
| 触发条件 | 该涨跌幅**绝对值 ≥ 0.2%** |
| 方向 | 顺势：上涨做多，下跌做空 |
| 入场价 | **第 2 秒收盘价** |
| 止损 / 止盈 | 0.5% / 1.0% |
| 超时 | 30 分钟按市价离场 |

**关键改进：筛选条件与入场价都只用前两秒数据，实时可判定。** 之前版本用「第 10 秒达标」筛选却在更早入场，属于前视偏差，本次已消除。

分析脚本：`scripts/analyse_second2_entry.cjs`（6 项单元测试）。

对比扩大前：0.2% 阈值从 33 笔增至 **51 笔**，0.3% 从 16 笔增至 **23 笔**。

### 各事件的触发率

## 七、参数网格概览

共测试 **90 组**参数，在 0.1% 成本下为正的从旧样本的 **56 组降至 22 组**。

表现最好的几组**全部是 0.3% 阈值**，最优组扣成本后 +3.09%（23 笔，胜率仅 47.8%）。

**胜率低于 50% 却能盈利，靠的是 1.5% 止盈的高盈亏比。** 这种结构对滑点极度敏感：一旦实际滑点抬高成本或降低止盈达成率，优势即刻消失。

最差组为 0.15% 阈值组合，扣成本后 **-7.99%**。

## 八、局限

1. **胜率 51.0%。** 51 笔交易中 26 胜 25 负，其 95% 置信区间约为 37% 至 65%，**与随机无法区分**。
2. **止损远多于止盈**：20 笔止损、12 笔止盈、19 笔超时。盈利依赖少数大幅止盈，结构脆弱。
3. **秒级成交假设过于理想。** 公布后第 2 秒是**流动性最差、价格跳动最剧烈**的时刻，实际滑点可能远超 0.1%。
4. **要求极低的系统延迟。** 从数据公布到第 2 秒结束只有 2 秒，**人工操作无法执行**。
5. **扩大覆盖面已被验证无效**：PPI 所在的其他类触发 11 笔但为亏损，说明问题不在事件数量。
6. **未考虑资金费率与合约强平风险**，本文按现货测算。

## 九、结论与建议

### 本次扩大样本回答了什么

**问题：三年只有 16 个信号，是不是因为盯的事件太少？**

**答案：不是。** 扩大到 161 个窗口后：

- 信号量确实翻倍（0.2% 阈值从 33 笔增至 **51 笔**，年均 **18.9 次**）。
- **但优势同步消失**：胜率 57.6% → 51.0%，扣成本后从 +1.90% 降到 **+0.12%**（平均每笔 +0.002%）。

**这说明早期的优异表现是小样本假象，而非覆盖面不足。**

### 已被两次独立样本确认的事实

- **冲击集中在第 2 秒**：第 1 秒入场收益 +20.23%，第 2 秒 +5.22%，**晚一秒交出大部分利润**。
- **第 2 秒仍是可执行时点中最优的**，第 3 秒起明显转负。
- **阈值必须足够高**：只有 0.3% 阈值的顺逆幅度结构有利。
- **样本外持续衰减**：两次切分检验都显示后半段接近或低于零。

### 不建议继续的方向

1. **不要再加事件类型。** GDP、PCE、零售、ISM、讲话类触发率为 0；PPI 所在的其他类触发 11 笔但交易亏损。
2. **不要采用 0.3% 阈值的最优参数。** 那 23 笔交易胜率仅 47.8%，靠 1.5% 止盈拉高收益，对滑点极度敏感。
3. **不要继续调参。** 90 组参数中仅 22 组在成本下为正，且高度集中在同一区域。

### 如果还要继续

1. **先测真实滑点**，这是唯一能改变结论的变量。若单边滑点超过 0.05%，本方案可以直接放弃。
2. **验证能否在 2 秒内完成全链路**，做不到就无需继续。
3. **考虑改变方向**：数据显示公布后振幅显著放大且稳定，**波动率交易比方向性交易更有依据**。
